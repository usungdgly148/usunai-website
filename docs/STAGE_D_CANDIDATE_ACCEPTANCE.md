# 阶段 D：全量回归与候选发布验收

更新日期：2026-08-20

## 安全边界

- 本阶段只准备恢复分支的候选版本，不合并 `main`，不部署生产。
- 自动测试使用系统临时目录和运行时随机凭证；不读取或写入生产数据库。
- 不自动调用会产生费用的 DeepSeek、百炼、Coze 或 Qdrant 真实接口。
- 真实模型首字耗时、计费和第三方稳定性，必须在人工确认候选部署后再验收。

## 自动回归

`npm run check:stage-d` 包含：

1. 三种智能体平台、DeepSeek 流式事件、思考过程、知识库与 RAG 静态契约检查。
2. 隔离启动真实 Node 后端与 SQLite 数据层。
3. 邮箱注册、双会话登录、会话恢复与单设备退出撤销。
4. 跨会话历史记录写入、读取和用户数据隔离。
5. 单条资产保存与跨会话读取。
6. 管理员元数据接口不返回真实 API Token；只有显式 `reveal-token` 接口可查看。
7. 套餐点数以服务端配置为准，有效期同步写入用户与注册镜像。
8. 算力流水、订单记录同时落库，重复请求不会重复加点。

GitHub Actions 会先安装服务端依赖，再运行完整 `npm run verify`，随后安装并构建前端。

## 隔离候选构建

运行：

```bash
npm run candidate:build -- <candidate-label>
```

输出位于 `.tmp/candidates/<candidate-label>/`，包含独立 `dist/` 与 `manifest.json` SHA-256 清单，不覆盖生产或仓库根目录的静态文件。

本地候选 `stage-d-final` 构建结果：

- 文件数：3
- 总大小：1,030,450 bytes
- `manifest.json` SHA-256：`408f1267188a776d28eb866de0123909cc39a6efc67a716cc79be90d8a275f46`
- 非阻断提示：主 JavaScript 包约 918 KB，后续可单独进行代码拆分，不在阶段 D 扩大修改。

## 发布前人工验收清单

以下项目不会在本阶段自动写生产数据：

- 桌面端、iOS Safari、Android Chrome 的登录、聊天、工作流、资产与历史交互。
- Coze 新版、Coze 旧版、DeepSeek 原生模型各执行一次真实任务。
- DeepSeek 思考过程、首字耗时 P50/P95、总耗时、错误率与成本。
- 百炼向量化、知识库上传/替换/删除、RAG 检索命中与回答质量。
- 管理后台套餐充值、手动调整、算力流水和订单的真实账号一致性。

只有以上人工验收通过并得到明确部署确认后，才允许进入生产发布。
