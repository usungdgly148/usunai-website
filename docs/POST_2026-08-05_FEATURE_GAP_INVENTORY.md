## 1. 清单目的与边界

本清单用于把 2026-08-05 左右的可构建 React/Vite 源码恢复到当前生产网站的功能水平。核对依据包括：

1. 恢复前端源码：`frontend/src/`
2. 当前生产前端产物：`dist/`
3. 当前可维护后端源码：`server/`
4. 本次任务对话中确认过的最终需求与验收反馈

本清单不授权部署。恢复源码、当前生产 `dist/` 和线上服务器必须继续隔离，直到候选构建通过完整回归测试并获得人工确认。

## 2. 状态说明

| 状态 | 含义 |
|---|---|
| 已有 | 恢复源码已包含主要实现，只需保留并回归验证 |
| 部分 | 恢复源码有基础实现，但缺少当前生产的最终修复或 UI |
| 生产独有 | 当前生产前端已实现，但只存在于编译产物或独立补丁中，需要重建 JSX |
| 后端已备 | 后端源码和接口完整，前端可维护源码缺失 |
| 运维项 | 不属于 React 前端恢复范围，需要单独维护 |

优先级定义：`P0` 为生产数据、安全或当前线上核心能力；`P1` 为主要交互与移动端体验；`P2` 为增强与回归项。

## 8. 完成定义

只有同时满足以下条件，才可认为前端源码恢复完成：

- `frontend/` 可由干净环境执行 `npm ci && npm run build`。
- 构建产物不依赖手工注入的补丁 JS。
- 当前生产所有 P0/P1 功能在源码构建中通过回归。
- 源码、后端接口、数据库字段和前后台展示口径一致。
- GitHub 凭证扫描、基线检查和前端构建全部通过。
- 有候选版本、备份与回滚点，并经过人工批准；不得直接覆盖生产。
