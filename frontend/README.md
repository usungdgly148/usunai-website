# 前端源码恢复基线

本目录保存从本地历史工程中白名单恢复的 React/Vite 前端源码。

## 当前状态

- 源码快照时间约为 2026-08-05。
- 可以通过 `npm ci` 和 `npm run build` 独立构建。
- 这是当前生产前端的祖先版本，不等同于线上完整版本。
- 2026-08-05 之后的 DeepSeek、RAG、知识库、教程配置和其他补丁仍需逐项回迁。
- 已移除历史 mock 中的真实格式 PAT 字符串，并修正入口标题和 favicon。

## 安全边界

- 本目录暂时只用于源码恢复、构建验证和功能回迁。
- 禁止直接把本目录构建结果部署到生产环境。
- 不得提交 `.env`、真实 API Key、Token、私钥、用户数据或运行时文件。
- 只有在功能与当前生产版本一致、回归测试通过且具备回滚点后，才可讨论替换生产 `dist/`。

## 本地构建

```bash
npm ci
npm run build
```

构建输出为本目录下的 `dist/`，该目录不会提交到 GitHub。
